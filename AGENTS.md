# AI Offer Creator

Read `docs/ARCHITECTURE.md`, `docs/OPERATIONS.md` and `docs/VALIDATION.md` before changes.

Keep the existing questions, calculations, API response shapes and exports intact when changing presentation. The tool is framed inside the member resource page and serves its own bundled CSS across origins. Check both 1280 and 390 pixel outer browser widths.

Never print credentials, environment files or authorization headers. Keep keys in the deployment environment. Do not commit generated uploads, usage records or local databases.

A push to `main` automatically releases production on Railway. Prepare and validate on a review branch first. The owner runs the production trigger, 1 app at a time. Do not push `main` as an ordinary documentation update.

Use the configured Git author. Stage only explicit paths. Commit messages and tag annotations describe the change.
